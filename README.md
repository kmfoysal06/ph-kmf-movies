# KMF Movies - Movie Information Application
KMF Movies is a web application that provides users with detailed information about movies including ratings, and more. The application is built using React, React Router, and Tailwind CSS for a responsive and user-friendly interface.

## Features
- View detailed information about movies, including ratings, summaries, and cast details.
- Search for movies by title.

## API
The application fetches movie data from the [TVMaze API](https://www.tvmaze.com/api). This API provides comprehensive information about movies and TV shows, including ratings, summaries, and cast details.
